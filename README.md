# Калькулятор Pro 👑

Шуточный калькулятор: цифры жмутся как обычно, а за кнопку «=» он просит оформить подписку за 99 ₽/месяц. После «оплаты» (фейковой, деньги не списываются) долго думает и на любой пример отвечает **Hello World**.

**Открыть:** https://sempik.github.io/calc/

Один файл `index.html`, без зависимостей.
